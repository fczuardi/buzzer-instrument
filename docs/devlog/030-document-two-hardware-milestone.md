# Slice 030: Document Two-Hardware Milestone

The repository migration and the second hardware showcase made the old
buzzer-only milestone language obsolete.

The root README now describes the current result as one shared monophonic
instrument policy rendered through two M5 audio outputs: the M5StickC Plus2
buzzer and the M5Stack Core Gray speaker. It also distinguishes the local test
apps from the BLE MIDI compositions owned by `embedded-music-experiments`.

The environment and CI sections now name both validated devices and both local
app builds. This slice changes documentation only; it does not change package
APIs, firmware, calibration, or hardware behavior.
